Understanding Causal Effects: Path Coefficients, Direct Effects, and Total Effects

Author

Claude Sonnet 4.5 with Extended Thinking as Requested by Todd R. Johnson

Introduction

This document demonstrates the key distinctions between:

  • Path coefficients in linear structural equation models
  • Direct effects (controlled and natural)
  • Total effects and indirect effects
  • How these concepts differ in linear vs. non-linear models
  • The connection to causal DAGs

Key Point: In the linear model without interaction:

  • Path coefficient c_prime (X→Y) = Direct Effect = 0.3
  • Path coefficient a (X→M) × path coefficient b (M→Y) = Indirect Effect = 0.5 × 0.4 = 0.2
  • Total Effect = Direct + Indirect = 0.3 + 0.2 = 0.5

Controlled Direct Effect (CDE)

In the linear model, the CDE is the same for all values of M:

Code

Controlled Direct Effect (CDE) - Now Varies with m

With interaction, the CDE depends on the level of M:

Code 
# Extract coefficients
theta0 <- coef(m2_int)["(Intercept)"]
theta1 <- coef(m2_int)["X"]
theta2 <- coef(m2_int)["M"]
theta3 <- coef(m2_int)["X:M"]

# CDE(m) = theta1 + theta3*m
# This is the effect of changing X by 1 unit when M is held at level m

m_values <- seq(-2, 2, by = 0.2)
cde_interaction <- tibble(
  m = m_values,
  CDE = theta1 + theta3 * m_values
)

ggplot(cde_interaction, aes(x = m, y = CDE)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(alpha = 0.5) +
  geom_hline(yintercept = theta1, linetype = "dashed", color = "red",
             alpha = 0.5) +
  annotate("text", x = 0, y = theta1 + 0.05, 
           label = "Pure Direct Effect", color = "red") +
  labs(title = "Controlled Direct Effect with Interaction",
       subtitle = "CDE(m) = θ₁ + θ₃×m varies with the level of mediator",

Key Insight: With interaction, there is no single “direct effect” - it depends on where you fix the mediator!

Natural Direct and Indirect Effects with Interaction

Code 
# For binary X going from 0 to 1, with continuous M
# We'll use the formulas from VanderWeele (2015)

# Coefficients from regressions
beta0 <- coef(m1_int)["(Intercept)"]
beta1 <- coef(m1_int)["X"]  # a path

# Calculate E[M|X=0]
mean_M_X0 <- beta0

# Pure NDE (holds M at level when X=0)
# NDE_pure = (theta1 + theta3 * E[M|X=0])
nde_pure <- theta1 + theta3 * mean_M_X0

# Total NDE (holds M at level when X=1) 
mean_M_X1 <- beta0 + beta1
nde_total <- theta1 + theta3 * mean_M_X1

# Pure NIE (changes M from X=0 to X=1, keeps X at 0)
nie_pure <- (theta2 * beta1) + (theta3 * beta1 * mean_M_X0)

# Total NIE (changes M from X=0 to X=1, keeps X at 1)
nie_total <- (theta2 * beta1) + (theta3 * beta1 * mean_M_X1)

# Total effect
total_effect <- coef(m3_int)["X"]

effects_df <- tibble(
  Effect = c("Pure NDE", "Total NDE", "Pure NIE", "Total NIE", 
             "Pure NDE + Pure NIE", "Total NDE + Total NIE", "Total Effect"),
  Value = c(nde_pure, nde_total, nie_pure, nie_total,
            nde_pure + nie_pure, nde_total + nie_total, total_effect)
)

kable(effects_df, 
      caption = "Natural Direct and Indirect Effects with Interaction",
      digits = 3) %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

Key Observations:

  1. Pure NDE + Pure NIE = Total Effect ✓
  2. Total NDE + Total NIE = Total Effect ✓
  3. Pure NDE ≠ Total NDE (they differ in how they handle the X×M interaction)
  4. Pure NIE ≠ Total NIE (they differ in how they handle the X×M interaction)
  5. The “pure” effects attribute the interaction to the indirect effect
  6. The “total” effects attribute the interaction to the direct effect

Part 4: Practical Example with Interpretation

Let’s create a realistic example: effect of education (X) on income (Y) mediated by job prestige (M).

Code 
# Generate realistic data
set.seed(456)
n <- 2000

practical_data <- tibble(
  education = rnorm(n, mean = 14, sd = 2),  # Years of education
  e_prestige = rnorm(n, mean = 0, sd = 5),
  e_income = rnorm(n, mean = 0, sd = 8)
) %>%
  mutate(
    prestige = 3 * education + e_prestige,  # Job prestige score

Part 5: Connection to DAGs and Assumptions

Required Assumptions for Identification

Code 
# Create a more complex DAG showing confounders
dag_confounded <- dagitty('dag {
  X -> M
  M -> Y
  X -> Y
  C -> X
  C -> Y
  C -> M
}')

tidy_dag <- tidy_dagitty(dag_confounded)

ggdag(tidy_dag) +
  theme_dag() +
  ggtitle("Mediation with Confounding") +
  geom_dag_text(color = "white") +
  geom_dag_edges() +
  geom_dag_node(aes(color = name == "C")) +
  scale_color_manual(values = c("TRUE" = "red", "FALSE" = "steelblue"),
                     guide = "none")

Key Assumptions for Natural Direct/Indirect Effects:

  1. No unmeasured X → Y confounding (conditional on C)
  2. No unmeasured M → Y confounding (conditional on C and X)
  3. No unmeasured X → M confounding (conditional on C)
  4. No M → Y confounders affected by X (this is the strong one!)

The fourth assumption is often violated in practice - this is why controlled direct effects are sometimes preferred (they only need assumptions 1-3).

Summary and Key Takeaways

1. Linear Models (No Interaction)

  • Path coefficients = Causal direct effects
  • CDE = NDE = path coefficient on X→Y
  • Simple decomposition: TE = DE + IE
  • Effects are transportable across contexts

2. Models with Interaction

  • Path coefficients ≠ Causal effects (effects are conditional)
  • CDE varies with level of mediator M
  • NDE requires counterfactual reasoning
  • Two valid decompositions (pure vs. total)
  • Effects are context-dependent

3. Practical Implications

  • Always check for interactions before interpreting “direct effects”
  • CDE is useful for policy questions: “What if we set M to m?”
  • NDE is useful for mechanism questions: “What’s the effect not through M?”
  • Natural effects require stronger assumptions than controlled effects

4. Relationship to DAGs

  • DAGs show causal structure (not necessarily linear relationships)
  • Arrows represent direct causal effects
  • d-separation helps identify confounding
  • Same DAG can represent linear or non-linear models
